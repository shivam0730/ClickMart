# YourStore

An e-commerce platform built with Next.js 15, Redux Toolkit, Prisma, and Tailwind CSS.

## Features
- Product browsing and search
- Shopping cart
- Multi-store support
- Admin dashboard
- Seller dashboard

## Tech Stack
- Next.js 15
- React 19
- Redux Toolkit
- Prisma + SQLite
- Tailwind CSS 4

## Setup
\`\`\`bash
npm install
npx prisma migrate dev
npm run dev
\`\`\`
